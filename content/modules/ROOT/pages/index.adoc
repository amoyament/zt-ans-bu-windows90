== What you'll learn

In this hands-on workshop, you will automate a Windows server with Red Hat Ansible Automation Platform. You will set up automation controller, run ad-hoc commands and playbooks, publish that automation as job templates and roles, and then patch Windows, install software with Chocolatey, and connect the jobs in a workflow.

You do the work from the controller web interface and Visual Studio Code. The Windows host is already part of your inventory.

== The challenge

Windows administration often depends on manual updates, one-off software installs, and console changes that are hard to repeat or hand to someone else. Your organization has Ansible Automation Platform, but the Windows work is still outside that pipeline.

This workshop puts that work into automation controller: credentials, a project, an inventory, and job templates a teammate can run again. Later exercises add Windows updates, Chocolatey package management, and a workflow that runs those jobs in order.
